# 手环与手机的状态文案

手环只分三种显示，不解释原因。

- 有导航：有效转向。显示方向标题、距离、路名和出口，与改前相同。
- 暂无导航：导航已结束、尚未开始、当前指令无法识别，或动作不在 14 个允许动作内。标题固定为“暂无导航”。
- 连接中：链路断开，或 15 秒没有收到帧。与改前相同。

手环不写原因，是因为屏幕窄，换行后仍然看不出为什么没有导航。用户已于 2026-10-22 定：原因全部放在手机端。

手机端原句：

- 等待导航，且开始导航时自动拉起手环页开着：在高德开始步行或骑行导航，手环导航页会自动打开。
- 等待导航，且该开关关着：请在手环打开导航页，再在高德开始导航。
- 手机刚重启恢复出来的状态（id 以 restore- 开头）按等待导航处理，不是故障。
- 信息暂不可用，且转向动作为空或不在 14 个允许动作内：高德给出的转向动作无法识别，手环不会显示猜测的方向。
- 信息暂不可用，且高德正在导航：高德正在导航，但这条提示读不出转向方向。手环不会显示猜测的方向，请看高德或等下一条提示。
- 信息暂不可用，且没有读到高德导航提示：没有读到高德的导航提示：导航可能已结束，或高德已退出。要继续请回到高德重新开始导航。
- 信息暂不可用的标题仍是“信息暂不可用”。

居中与新文案在真机上的观感未验证。
