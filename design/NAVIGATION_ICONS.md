# 导航图标与动作语义

设计版本 1.1，2026-10-12。此清单扩充界面与矢量资源，不代表高德通知解析已支持全部动作；实现时按真实通知样本建立映射。

| 图标 ID | 中文动作 | 使用边界 |
|---|---|---|
| left / right | 左转 / 右转 | 普通方向 |
| straight | 直行 | 保持前进方向 |
| slight-left / slight-right | 向左前方 / 向右前方 | 与靠左靠右分开表达 |
| sharp-left / sharp-right | 向左后方 / 向右后方 | 与掉头分开表达 |
| keep-left / keep-right | 靠左行驶 / 靠右行驶 | 分岔或车道选择，不表示普通转弯 |
| uturn-left / uturn-right | 左侧掉头 / 右侧掉头 | 侧向必须有源数据依据；不能从“掉头”两个字猜侧向 |
| roundabout-enter | 进入环岛 | 不推测出口编号 |
| roundabout-exit | 驶出环岛 | 出口编号是独立数据；预览采用明确标记的第 2 出口示例 |
| arrive | 到达目的地 | 与用户手动结束导航区分；不显示虚构的转向距离 |

共 14 个导航图标，导出路径为 `svg/icon-<id>.svg`。新增手环画板采用同一大箭头、距离与道路名布局。到达页面显示“已到达 / 目的地”；断连、无法识别和导航结束仍保留原有专门状态。

图标不是方向识别的替代物。遇到未能识别的动作仍显示“信息暂不可用”，不能默认直行；若数据只包含泛化掉头，则须在解析样本验证后决定对应的无侧向表达方式。步行不强行显示仅适用于车道选择的动作。

本地预览增加图标选择区，点击图标切换手机与手环示例；切换图标会回到有效导航展示。提醒距离仍采用步行 30 米、骑行 100 米，新增图标不改变已经确认的提醒规则。
